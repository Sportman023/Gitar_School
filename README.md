# 🎸 Гитарная школа

Домашний тренажёр по музыкальной грамоте. Приложение задумано так, чтобы
дописывать в него новые темы по мере того, как их проходят в школе.

**Открыть:** https://sportman023.github.io/Gitar_School/

Работает прямо в браузере, без сервера и без интернета после первого запуска.
На одном устройстве могут заниматься несколько детей — у каждого свои звёзды
и своя гитара.

Первый блок: **ноты и цвета радуги**.

| Нота | Цвет | Лат. | На стане |
|------|------|------|----------|
| До   | Красный    | C | добавочная линейка снизу |
| Ре   | Оранжевый  | D | под первой линейкой |
| Ми   | Жёлтый     | E | первая линейка |
| Фа   | Зелёный    | F | между 1-й и 2-й |
| Соль | Голубой    | G | вторая линейка |
| Ля   | Синий      | A | между 2-й и 3-й |
| Си   | Фиолетовый | B | третья линейка |

## Запуск на компьютере

Приложение — это просто файлы в `public/`. Для локальной разработки есть
мини-сервер, нужен только Node.js 18+, зависимостей нет.

```bash
npm start          # затем открыть http://localhost:3000
npm run dev        # то же самое, но с авто-перезапуском при правках
PORT=8080 npm start
```

Публикация на GitHub Pages происходит сама: после `git push` в ветку `main`
GitHub Actions выкладывает папку `public/` (см. `.github/workflows/pages.yml`).

## Что внутри

**Игроки.** При каждом запуске приложение спрашивает «Кто сегодня играет?».
У игрока есть имя и зверёк; звёзды, результаты, настройки и гитара у каждого
свои. Сменить игрока — кнопка со зверьком в шапке, изменить или удалить —
карандаш на карточке игрока. Всё хранится в браузере (`localStorage`) и никуда
не отправляется; если очистить данные браузера, прогресс пропадёт.

**Моя гитара.** Звёзды за игры не тратятся, а открывают детали для гитары:
формы корпуса, цвета, наклейки (до трёх сразу) и эффекты. Ребёнок сам собирает
гитару в мастерской. На главном экране видно текущую гитару и сколько звёзд
осталось до следующей детали, а когда что-то открывается — появляется подарок.

| Звёзд | Что открывается |
|------:|-----------------|
| 0     | классическая форма, цвета «Дерево» и «Красный», наклейка «Звёздочка» |
| 10–50 | наклейки «Сердечко», «Нотка», цвета «Оранжевый», «Жёлтый» |
| 70–250 | форма «Сердечко», цвета «Зелёный», «Голубой», «Синий», наклейки «Молния», «Цветок», эффект «Блёстки», форма «Электрогитара» |
| 290–650 | цвета «Фиолетовый», «Розовый», «Радуга», наклейки «Смайлик», «Радуга», эффект «Сияние», форма «Звезда» |
| 750–1500 | наклейка «Корона», форма «Стрела», цвета «Золото» и «Космос», эффект «Огонь» |

Точные пороги и названия — в `public/js/data/guitar.js`.

**Ноты и цвета**

* **Учим ноты** — карточки с названием и цветом ноты; нажатие проигрывает её на фортепиано.
* **Нота → Цвет** — показываем ноту, ребёнок выбирает цвет.
* **Цвет → Нота** — наоборот.
* **Собери радугу** — расставить ноты по порядку от До до Си.
* **Угадай на слух** — на фортепиано звучит опорная До, потом загаданная нота.
  Все ноты из первой октавы (До–Си), так что загадка всегда не ниже опорной До.

**Нотный стан, первая октава**

* **Ноты на стане** — все семь нот в скрипичном ключе с подсказкой, где каждая живёт.
* **Читаем ноты** — показываем ноту на стане, ребёнок называет её.
* **Ставим ноты** — наоборот: дано название, надо выбрать правильный стан.

**Вторая октава**

* **Ноты второй октавы** — лесенка из двух октав на одном стане (каждую нотку можно
  послушать) и карточки До–Соль: где нота живёт на стане.
* **Читаем ноты**, **Ставим ноты** — те же игры, что и для первой октавы, только
  с нотами До–Соль второй октавы.
* **Первая или вторая?** — ноты обеих октав вперемешку, ответ — имя и октава.
  Среди вариантов всегда есть такая же нота из другой октавы: цвет у них одинаковый,
  так что октаву приходится читать по стану.

Переключатель **«цветные нотки»** закрашивает головки нот цветами радуги — опора на
уже выученное. Когда станет легко, его выключают, и ноты становятся чёрными, как в
настоящей нотной тетради. В обратном задании («Ставим ноты») ноты всегда чёрные:
иначе цвет подсказывал бы ответ, и стан можно было бы не читать.

### Ноты первой октавы на стане

| Нота | Где стоит | Штиль |
|------|-----------|-------|
| До   | на добавочной линеечке под станом | вверх |
| Ре   | под первой линейкой | вверх |
| Ми   | на первой линейке | вверх |
| Фа   | между 1-й и 2-й линейками | вверх |
| Соль | на второй линейке (вокруг неё завиток ключа) | вверх |
| Ля   | между 2-й и 3-й линейками | вверх |
| Си   | на третьей линейке | вниз |

### Ноты второй октавы

Пока только До–Соль, Ля и Си второй октавы появятся позже.

| Нота | Где стоит на стане |
|------|--------------------|
| До   | между 3-й и 4-й линейками |
| Ре   | на четвёртой линейке      |
| Ми   | между 4-й и 5-й линейками |
| Фа   | на пятой линейке          |
| Соль | над пятой линейкой        |

Штиль у всех нот второй октавы направлен вниз. Цвета те же, что и у первой
октавы: цвет — это имя ноты, а не её высота. В играх с названием ноты теперь
подписана и октава («До / второй октавы»).

## Звук

Струны гитары и сигналы «верно / неверно» синтезируются прямо в браузере.
В «Учим ноты» и «Угадай на слух» звучит настоящий рояль: записи
[Salamander Grand Piano](https://archive.org/details/SalamanderGrandPianoV3)
(Yamaha C5), автор — Alexander Holm, лицензия
[CC BY 3.0](http://creativecommons.org/licenses/by/3.0/). Рояль записан через
малую терцию, поэтому в `public/audio/piano/` лежат только пять клавиш (До, Ре♯,
Фа♯, Ля первой октавы и До второй), остальные ноты получаются из ближайшей записи
сдвигом на полутон. Громкость записей выравнивается, чтобы она не подсказывала ответ.

## На планшете

1. Открыть https://sportman023.github.io/Gitar_School/ в Chrome.
2. Меню → «Установить приложение» (или «Добавить на главный экран»).
   Появится иконка, приложение откроется на весь экран и будет работать
   без интернета.

## Как добавить новую тему

1. Создать файл в `public/js/modules/`, экспортировать объект:

```js
export default {
  id: 'ritm',
  title: 'Длительности',
  subtitle: 'Целая, половинная, четверть',
  emoji: '🥁',
  accent: '#26A69A',
  mount(root) {
    // draw the section inside root
    // optionally return a cleanup function
  },
};
```

2. Добавить его в список `MODULES` в `public/js/modules/index.js`.
   Поле `group` определяет, под каким заголовком раздел появится в меню.

Для викторин с вариантами ответа есть готовый движок `createQuiz()`
из `public/js/core/quiz.js` — нужно описать только вид вопроса и ответов.
Набор нот задаётся полем `notes` (по умолчанию первая октава), неправильные
варианты — `pickOthers`, текст при ошибке — `explainAnswer`.

## Структура

```
server.js                  мини-сервер для запуска на компьютере
.github/workflows/pages.yml публикация public/ на GitHub Pages
public/
  index.html               оболочка
  styles.css               оформление
  sw.js                    работа без интернета (service worker)
  js/app.js                переходы между экранами, главный экран, подарки
  js/data/notes.js         ноты обеих октав, цвета, частоты и места на стане
  js/data/guitar.js        детали для гитары и сколько звёзд нужно на каждую
  js/core/audio.js         синтез звука струны и сигналов (Web Audio)
  js/core/piano.js         фортепиано из записей настоящего рояля
  audio/piano/             записи клавиш рояля
  js/core/staff.js         нотоносец с одной нотой и лесенка нот подряд (SVG)
  js/core/guitar.js        рисунок гитары игрока (SVG)
  js/core/controls.js      общие элементы управления (переключатель цвета)
  js/core/store.js         игроки, прогресс и звёзды (localStorage)
  js/core/quiz.js          движок викторин
  js/core/ui.js            мелкие помощники для вёрстки
  js/modules/              разделы приложения
  js/screens/              экраны вне меню: выбор игрока, мастерская гитары
tools/make-icons.mjs       генератор иконок (npm run icons)
```
